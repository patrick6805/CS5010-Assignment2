# Number Pattern

A simple Python program that uses recursion to print a number pattern based on two user-provided integers. The pattern decreases by a specified interval until reaching a negative number, then prints the numbers in reverse order.

## How to Run

1. Make sure Python 3 is installed.
2. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
3. Navigate to the project directory:
   ```bash
   cd <repository-folder>
   ```
4. Run the program:
   ```bash
   python main.py
   ```
5. Enter two integers when prompted:
   - First integer: Starting number.
   - Second integer: Decrement value.

## Example

**Input:**
```text
12
3
```

**Output:**
```text
12 9 6 3 0 -3 0 3 6 9 12
```
